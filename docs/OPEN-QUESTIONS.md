# 未確定事項リスト（Open Questions）

実装に入る前に決めておきたい論点。優先度は以下の 3 段階。

- **P0**: 最初の PR（M0-1）をブロックする。今すぐ決めたい
- **P1**: v0.1 の途中までに決めたい。後から変えると手戻りが大きい
- **P2**: v0.3 以降で決めればよい

決まった項目は「決定」欄に記入し、根拠を `docs/adr/` に ADR として残す。

## E. 決定が要らない（このまま進める）事項

念のため明示しておく。異論があれば指摘してほしい。

- ノード ID は `int`（2^31 ノード上限、約 32 GB）。64bit 版は作らない
- 一意化表・状態表は自前のオープンアドレス法（`Dictionary` は使わない）
- 家族代数演算は**すべて反復実装**（再帰禁止）
- 演算キャッシュは lossy direct-mapped（衝突は上書き）
- 参照カウントは実装しない
- 参考 OSS のコードはコピーせず、論文・ドキュメントから再実装する
- テストは xUnit ＋ CsCheck（プロパティテスト）＋ 総当たり照合
