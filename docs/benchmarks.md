# パフォーマンス

2026-09-07 にこのマシンで再測定した結果。要件・実装経緯ではなく、機能ごとの実測値だけを載せる。

## 環境と方法

| 項目 | 値 |
|---|---|
| CPU | AMD Ryzen 5 2400G、8 論理コア |
| OS / .NET | Ubuntu 26.04.1 LTS、.NET 10.0.111、Server GC |
| 安全装置 | 1 秒ごとにメモリ使用率を監視し、90%超で計測を終了 |

単体構築は1回、比較は独立プロセスで複数回実行した最小値。全計測は上限に達せず完走した。

```bash
dotnet run -c Release --project bench/ZDD.Net.Benchmarks -- stats
dotnet run -c Release --project bench/ZDD.Net.Benchmarks -- time Path_Grid9x9
```
