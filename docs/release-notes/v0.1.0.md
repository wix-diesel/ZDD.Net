# v0.1.0 リリースノート（2026-08-31）

M1「Core エンジン」マイルストーン（[docs/PLAN.md](../PLAN.md) §12）の完了リリース。
ZDD Core エンジンが単体で完結し、外部から「Core だけでも使える .NET 製 ZDD ライブラリ」
として触れる状態になった。

## ハイライト

- `ZddManager` / `Zdd` を中心に、集合演算・ZDD 固有演算（Minato の基本演算）・
  問い合わせ／列挙・ranking／sampling・重み最適化・カスタム評価器・DOT 出力まで、
  Core エンジンの API が一通り揃った
- すべての演算は**反復実装**（再帰なし）。変数 10 万件規模でもスタックオーバーフローしない
  ことを回帰テストで確認済み
- ブルートフォース照合テスト（`BruteForceFamily`）とプロパティテスト（CsCheck）により、
  全演算をランダム入力で検証する基盤を整備
- `src/ZDD.Net` は外部 NuGet 依存ゼロ
- API はプレリリース扱いで、v1.0 までは破壊的変更があり得る
