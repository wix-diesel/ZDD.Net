# v0.6.0 リリースノート（2026-09-05）

M6「API 拡充と相互運用」マイルストーン（[docs/PLAN.md](../PLAN.md) §12）の完了リリース。v1.0 に
向けたプレリリースとして公開する。v0.5 のリリース直後に行った他ライブラリ（Graphillion / TdZdd /
SAPPOROBDD / CUDD+EXTRA）との機能比較で見つかった、「エンジンはあるのに入口が無い」類の欠落を
埋めた（詳細は [docs/design/m6-api-expansion.md](../design/m6-api-expansion.md)）。次の M7 は
有向グラフ対応（v0.7、[docs/design/m7-directed-graphs.md](../design/m7-directed-graphs.md)）。

## ハイライト

- **決定済み未実装 API の穴埋め**: `Zdd.ComplementWithin` / `ZddManager.PowerSetOf`（部分ユニバースでの
  補集合）、`Zdd.EnumerateInto` / `MaxSetSize`（アロケーションなしの集合列挙）、
  `FrontierBuilder.TryBuild`（上限超過を例外ではなく戻り値で返す構築）。いずれも
  `docs/OPEN-QUESTIONS.md` で決めたまま未実装だった穴を埋めるもの
- **項目写像とマネージャ間転送**: `Zdd.MapItems`（同一マネージャ内、順序保存の高速経路）/
  `MapItemsTo`（一般置換とマネージャ間転送）/ `TransferTo`（変数を増やしたマネージャへの複製）。
  CUDD の `Cudd_bddPermute` に相当する「変数の張り替え」が今まで無かった
- **ユニバース／辺順序をまたぐ族の移送**: `SetUniverse<T>.Extend` / `SetSet<T>.ToUniverse` /
  `GraphSet.ToEdgeOrder`。別々に作った族や、`Optimize()` で辺順序を変えた族を、同じ
  ユニバース・辺順序に揃えてから合成できるようになった
- **Graphillion 由来の族操作**: `AddSomeItem` / `RemoveSomeItem` / `RemoveAddSomeItems`
  （局所探索・「1 手違いの解」を数える用途）、`CostAtMost` / `CostAtLeast` / `CostEquals`
  （コストフィルタ、フロンティア走査中に閾値を外れた枝を切る）
- **`GraphSet` の露出**: `Specs/` の 22 スペックのうち高レベル API から一切触れていなかった
  13 スペックが `GraphSet.ConnectedSubgraphs` / `SteinerTrees` / `Cuts` / `DegreeConstrained` /
  `EdgeCovers` / `Knapsacks` / `VertexCovers` / `DominatingSets` / `Partitions` /
  `BalancedPartitions` / `Colorings` / `RegularGraphs` / `DegreeDistributions` として使えるように
  なった
- **新規スペック 4 つ**: `InducedSubgraphSpec`（頂点誘導部分グラフ）、`BicliqueSpec`（完全二部部分
  グラフ）、`DegreeDistributionSpec`（次数分布制約）、`VertexGroupSpec`（頂点グループ連結制約）
- **統合ビルダ** `GraphConstraints` / `GraphSet.Graphs(graph, constraints)` / `gs.Where(constraints)`:
  Graphillion の単一入口 `graphs(degree_constraints=, num_edges=, num_comps=, no_loop=,
  vertex_groups=, graphset=, ...)` 相当
- **Graphillion 対応表の暫定版**を [docs/graphillion-mapping.md](../graphillion-mapping.md) に
  追加した（本番の移行ガイドは M8-4）
- API はプレリリース扱いで、v1.0 まで破壊的変更があり得る
