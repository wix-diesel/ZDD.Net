# v0.7.0 リリースノート（2026-09-06）

M7「有向グラフ対応」マイルストーン（[docs/PLAN.md](../PLAN.md) §12、
[docs/design/m7-directed-graphs.md](../design/m7-directed-graphs.md)）の完了リリース。v1.0 に
向けたプレリリースとして公開する。D1（主用途 = 経路列挙・数え上げ）の有向側を埋めるリリースで、
一方通行のある道路網や依存関係グラフの経路列挙・有向閉路・有向ハミルトンパス／閉路・
有向次数制約・arborescence（根つき有向全域木）が書けるようになった。次の M8 は安定化と公開
（v1.0、API 凍結）。

## ハイライト

- **`DirectedEdge` / `DirectedGraph`**: 有向グラフのデータ構造。`Edge` と違い `GetHashCode` が
  向きを区別する（`DirectedEdge(0,1) != DirectedEdge(1,0)`）ため、逆平行辺 `u→v` / `v→u` の
  共存を許容する（自己ループ・多重辺は無向側と揃えて拒否）。`Bidirected(graph)` / `ToUndirected()`
  で無向グラフと相互変換でき、`Grid` / `Complete` / `Cycle` / `Path` の生成ショートカットもある
- **フロンティア基盤の一般化**: `FrontierManager` が `DirectedGraph` からも構築できるようになった。
  内部型 `EdgeTopology` に端点対・接続辺リストを切り出し、`FrontierManager`/`EdgeOrdering` を
  有向・無向で共有する形にした（振る舞い不変のリファクタで、既存の `FrontierManager(Graph)` の
  結果は一切変わらない）
- **有向スペック 6 種**: `DirectedPathSpec`（有向 s–t 単純パス）、`DirectedCycleSpec`（有向単純
  閉路。逆平行 2 本による "digon" は除外）、`DirectedHamiltonianPathSpec` /
  `DirectedHamiltonianCycleSpec`、`DirectedDegreeConstraintSpec`（入次数・出次数を別々に制約）、
  `ArborescenceSpec`（根つき有向全域木）
- **`DirectedGraphSet`**: `GraphSet` と同じ使い心地の高レベル API（`Paths` / `Cycles` /
  `HamiltonianPaths` / `HamiltonianCycles` / `Arborescences` / `DegreeConstrained` と、
  `Including` / `Excluding` / `Larger` / `Smaller` などの構築時フィルタ）
- **有向グラフ I/O**: エッジリスト（`DirectedEdgeListGraph`）・簡易テキスト（`directed` ヘッダ、
  `LabeledDirectedGraph`）・DIMACS（`p arc`）の 3 形式。`SimpleTextGraph.ReadDirected` /
  `DimacsGraph.ReadDirected` は無向専用の `Read` とはメソッドを分けてあり、ヘッダと呼んだメソッドが
  食い違うと行番号つきの `GraphFormatException` になる。DOT 出力の `digraph` 対応は
  `DirectedGraphSet.ToDot`/`WriteDot` で提供する
- **既存 API に破壊的変更は無い**: `Graph` / `Edge` / `GraphSet` / 既存スペックのシグネチャは
  一切変えていない。`FrontierManager` はコンストラクタの追加のみ
- **有向のベンチ基準値**: `Bidirected` 双方向格子の無向比・一方通行混在格子・`K_n` の有向
  ハミルトン閉路・arborescence を [docs/benchmarks.md](../benchmarks.md) の M7-8 節に記録した。
  **性能目標は置かない**——有向は同じ頂点数でも変数（弧）の数がおよそ無向の 2 倍になるため、
  無向と同等の速度が出る保証は無く、「どれくらい遅くなるか」を測って記録することが目的
- API はプレリリース扱いで、v1.0 まで破壊的変更があり得る

## 対象外（D8）

以下は今回のスコープに含めていない。詳細とその理由は
[docs/design/m7-directed-graphs.md](../design/m7-directed-graphs.md) §1 のスコープ表を参照:

- 自己ループ・多重辺（同じ `u → v` が 2 本。逆平行の `u → v` / `v → u` は多重辺扱いしない）
- 混合グラフ（有向辺と無向辺の混在）
- DAG 部分グラフの列挙（トポロジカル順の状態が大きく、別途検討）
- Graphillion 互換 I/O の有向対応（Graphillion 側に有向グラフの概念が無いため、相互運用できる
  相手がいない「互換」を追加しない判断）
- 有向グラフの木分解ベース辺順序（v1.1 候補）
- フロー・最小費用流（ZDD の守備範囲外）
